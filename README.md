# Structural Equation Modelling with Amos: a weekly study guide

A Quarto book: six weeks of regression essentials, then Byrne's *Structural Equation Modeling with Amos* (3rd ed.) chapter by chapter, with 18 accessible interactive apps, a synthetic practice dataset and short "Going further" pages.

The published book: <https://trgoodale.github.io/SEM_Course/>

## Preview locally

Install [Quarto](https://quarto.org/docs/get-started/), then from this folder run:

```
quarto preview
```

## Publish to GitHub Pages

1. Push this folder to the `main` branch of <https://github.com/trgoodale/SEM_Course>.
2. In the repository, go to **Settings > Pages** and set **Source** to **GitHub Actions**.
3. Every push to `main` now renders the book and publishes it (see `.github/workflows/publish.yml`).

See the "Notes for tutors" appendix in the book for how the files are organised.
