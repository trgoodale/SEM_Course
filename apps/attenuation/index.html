Attenuation simulator

Measurement error in a predictor shrinks a regression slope towards zero, and error in either variable weakens a correlation. Set the true relationship and the reliabilities, then compare what you would observe with the truth.

Truth versus what you observe

Why this happens

Observed X = true X + error. The error adds variance to X but nothing to its covariance with Y, so the slope cov(X, Y) / var(X) shrinks by the reliability of X. The correlation shrinks by the square root of the product of the two reliabilities.

observed slope = true slope × reliability(X) observed r = true r × √(reliability(X) × reliability(Y))

Latent variables in SEM model the error explicitly, so the structural paths between latent variables estimate relationships between true scores.

Questions for your SEM log

  1. With reliability of X set to .70 (a common value for short scales), how much is the slope underestimated?
  2. Why does error in Y leave the slope unbiased but still lower the correlation and R²?
  3. Explain in your own words how a latent-variable model avoids this bias. What does it need from your data to do so?
